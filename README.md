# 💳 TransacaoFinanceira

## 🧾 Case para refatoração

---

## 🎯 Objetivo

Este projeto tem como objetivo a refatoração de um sistema de transações financeiras, corrigindo erros, melhorando a arquitetura e aplicando boas práticas de desenvolvimento.

---

## 📌 Passos a implementar

### 1. Correção de erros
- Corrigir o que for necessário para resolver erros de compilação.

---

### 2. Validação da regra de negócio
- Executar o programa e analisar a saída.
- Identificar e corrigir o motivo de:
  - Transações canceladas mesmo com saldo positivo
  - Transações aprovadas sem saldo suficiente

---

### 3. Refatoração de código
- Aplicar code review
- Refatorar com boas práticas:
  - SOLID
  - Design Patterns
  - Separação de responsabilidades

---

### 4. Testes unitários
- Implementar testes para validar regras de negócio:
  - Sucesso
  - Falha por saldo insuficiente
  - Falha por conta inválida

---

### 5. Entrega
- Criar repositório no GitHub
- Compartilhar o link conforme solicitado no case

---

## ⚠️ Observações

- Livre escolha de linguagem
- Deve respeitar funcionalidades originais
- Saídas do sistema devem ser mantidas
- Aplicação de boas práticas é essencial
